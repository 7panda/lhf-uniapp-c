# 首页页面逻辑详细说明

## 页面概述
这是一个基于Vue3 + uni-app框架的移动端首页页面，主要用于展示商品信息和分类导航。

### 核心技术栈
- **框架**: Vue3 + uni-app
- **组件库**: 自定义组件（s-layout、s-goods-card等）
- **状态管理**: sheep框架（自定义状态管理）

---

## 页面结构分析

### 模板部分 (template)
```vue
<s-layout title="首页" navbar="custom" tabbar="/pages/index/index" :navbarStyle="template.style?.navbar" onShareAppMessage>
```
- 使用`s-layout`作为根容器
- 自定义导航栏和底部tabbar
- 支持分享功能

### 主要展示区域
1. **商品卡片区域** (goods-block)
   - 使用`s-goods-card`组件
   - 支持多种展示模式和样式配置

## 数据配置

### 商品卡片配置 (goodsCard)
```javascript
const goodsCard = {
  data: {
    mode: 2, // 展示模式
    goodsFields: {
      title: { show: 1 },      // 显示标题
      subtitle: { show: 1 },   // 显示副标题
      price: { show: 1 },      // 显示价格
      original_price: { show: 1 }, // 显示原价
      sales: { show: 1 },      // 显示销量
      stock: { show: 0 }       // 隐藏库存
    },
    params: {
      orderField: 'sort',      // 排序字段
      orderSort: 'asc'         // 升序排列
    },
    borderRadiusTop: 6,         // 上边框圆角
    borderRadiusBottom: 6,      // 下边框圆角
    space: 8                    // 间距
  },
  style: {
    background: { type: "color" },
    marginLeft: 8,
    marginRight: 8,
    marginTop: 0,
    marginBottom: 10,
    borderRadiusTop: 0,
    borderRadiusBottom: 0,
    padding: 0
  }
};
```

### 分类数据
```javascript
const categoryList = ref([]); // 分类列表数据

function getCategoryList() {
  sheep.$api.category.list().then(res => {
    categoryList.value = res;
  });
}
```
